# Python Environment

This project is intended to run on Python 3.10. The conda environment installs
CUDA-enabled PyTorch by default.

## Option 1: Conda

Create or update the environment and install dependencies:

```powershell
cd yb_thesis
.\setup_env.ps1 -Mode conda
conda activate yb_thesis
```

If PowerShell blocks `.ps1` scripts, allow script execution only for the
current terminal session and then run the setup script again:

```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
.\setup_env.ps1 -Mode conda
```

Equivalent manual command:

```powershell
conda env create -f environment.yml
conda activate yb_thesis
```

If the environment already exists:

```powershell
conda env update -n yb_thesis -f environment.yml --prune
```

The pip dependency list includes `scikit-learn`, which is required for the
t-SNE embedding visualizations generated by `08_visualize_user_similarity.py`.

Verify the main runtime dependencies:

```powershell
python -c "import numpy, torch, ultralytics, cv2, sklearn; print('torch', torch.__version__); print('sklearn', sklearn.__version__); print('ok')"
```

Verify CUDA:

```powershell
python -c "import torch; print(torch.__version__); print(torch.version.cuda); print(torch.cuda.is_available())"
```

If CUDA is not available, reinstall PyTorch in the active conda environment:

```powershell
conda install pytorch torchvision pytorch-cuda=12.4 -c pytorch -c nvidia
```

## Option 2: Python venv

Create `.venv` with Python 3.10 and install dependencies:

```powershell
cd yb_thesis
.\setup_env.ps1 -Mode venv
.\.venv\Scripts\Activate.ps1
```

Equivalent manual command:

```powershell
py -3.10 -m venv .venv
.\.venv\Scripts\python.exe -m pip install --upgrade pip
.\.venv\Scripts\python.exe -m pip install -r requirements-venv.txt
```

## GPU note

The default install uses the package versions from `requirements.txt`.
If PyTorch does not detect CUDA, reinstall PyTorch with the CUDA wheel that
matches your local NVIDIA driver/CUDA setup.

```powershell
python -c "import torch; print(torch.__version__); print(torch.cuda.is_available())"
```
